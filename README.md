# bio_data_analysis_26
Project for the biodiversity data analysis course. The project is divided into two parts. 

##  PART ONE
Creation of a matrix containing all the data on the two selected alpine species, Cypripedium calceolus and Salamandra atra.

## PART TWO
Analysis of the data collected in the matrix to answer an ecological question regarding the two species.

> What are the differences in the ecological and climatic niches of the two alpine species, Cypripedium calceolus and Salamandra atra, and how might global climate change affect them?
